国内服务器一键部署

国内服务器 Ping 国外节点，沿用原有 HTTP API 协议

下载安装脚本 ↗
  1. 在国内服务器安装

    使用国内 Linux 服务器的 root 终端执行下方命令。支持使用 systemd 的 Debian / Ubuntu 及 RHEL 系；只需 Python 3、Ping 与 curl，不需要数据库。

  2. 回填接口地址

    安装时填写国内服务器的公网 IP 或域名，脚本会生成含独立密钥的完整接口地址。复制到“调度策略 → 健康探测 → 国内探测接口”，保留 {target}。

  3. 使用国内 ICMP 判定

    健康判定选择“仅国内 ICMP”，建议单次超时至少 6 秒。保存后点击“立即探测”，确认节点结果后再按需开启自动切换。

填写国内接口下载 API 源码 ↗

安装后由 systemd 保持运行并开机启动。默认端口 8788，请在国内服务器安全组与防火墙放行主控服务器访问；可通过 GTM_ALLOWED_CLIENTS 进一步限制来源。脚本不会替你更改防火墙规则。

接口与维护

格式：http://国内服务器:8788/ping?host={target}&token=安装时生成的密钥。成功返回 code=200，完整 Ping 后零回包返回 code=-2；接口、解析或系统异常返回未知结果。接口地址含密钥，请勿公开；公网使用建议配置 HTTPS，或限制为仅主控 IP 可访问。

查看服务：systemctl status cf-gtm-ping-api

查看日志：journalctl -u cf-gtm-ping-api -n 50 --no-pager

重复执行安装命令可更新程序并保留配置。卸载：bash /tmp/cf-gtm-ping-api-install.sh --uninstall
